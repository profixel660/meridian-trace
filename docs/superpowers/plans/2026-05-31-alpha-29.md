# Alpha-29 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix two SME-reported issues on the You're Ready setup screen: (1) add a persistent "My projects" escape link so users are never stuck when the backend dies, and (2) show "N chunks from M documents" instead of a bare count in the Documents summary tile.

**Architecture:** Issue 1 is frontend-only (two files). Issue 2 threads a new `chunks` counter through the backend import job → wizard state → API response → frontend interface → UI label. All backend tests live in `tests/e2e/test_wizard_api.py`; frontend verification is `tsc --noEmit` (no Jest setup in this project).

**Tech Stack:** Python/FastAPI (backend), Next.js/TypeScript/Tailwind (frontend), pytest + FastAPI TestClient (tests).
