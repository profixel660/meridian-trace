# Meridian Tauri icons

Tauri requires PNG/ICO/ICNS icons here before `npm run tauri build` will succeed. Drop the icon set generated by `npm run tauri icon <path-to-source.png>` here. Round 18 ships the real icons; round 16 left this directory empty intentionally to avoid checking in placeholder binaries.

Expected files (referenced from `../tauri.conf.json` → `bundle.icon`):

- `32x32.png`
- `128x128.png`
- `128x128@2x.png`
- `icon.icns`
- `icon.ico`

`npm run tauri icon` will generate all of the above (plus extra Windows Store / macOS sizes) from a single 1024x1024 source PNG.
